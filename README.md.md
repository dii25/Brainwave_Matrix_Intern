# Brainwave Matrix Internship - Sales Data Analysis

## Overview
This project involves analyzing sales data for a fictional retail store. The goal is to uncover insights such as:
- Total sales over time
- Sales by category
- Sales by region
- Top-selling products

## Dataset
The dataset contains the following columns:
- `Date`: Sale date
- `Product_ID`: Unique ID for product
- `Product_Name`: Name of the product
- `Category`: Product category
- `Quantity`: Number of units sold
- `Unit_Price`: Price per unit
- `Total_Sales`: Quantity × Unit Price
- `Region`: Sales location
